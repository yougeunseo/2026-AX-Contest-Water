# 대청호 조류 대발생 7일 선행 예측 듀얼 AI 앙상블 시스템
> **2026년도 AX 아이디어 경진대회 지정분석 부문 출품작** <br>
> 기후변화로 가속화되는 대청호 유해남조류(녹조) 대발생에 대응하기 위해, 수질·수리·기상 융합 데이터를 기반으로 7일 전 선제적 조기경보를 송출하는 실무형 듀얼 AI 앙상블 파이프라인입니다.

<br>

## 핵심 차별점 및 기술적 문제 해결 (Key Insights)

### 1. '데이터 누수(Data Leakage)' 함정 입증 및 극복
기존 물환경 AI 연구에서 빈번하게 사용되는 '일 단위 선형 보간(Linear Interpolation)'이 모델의 과적합을 유발함을 입증했습니다. 본 프로젝트는 보간법을 전면 배제하고, 결측치가 포함된 100% 실측 순수 데이터(Raw Data)만을 학습하여 현장에서 작동하는 진정한 모델 강건성(Robustness)을 확보했습니다.

### 2. 게으른 예측(Shadowing 현상) 타파를 위한 수학적 통제
'오늘의 세포수'를 그대로 학습하여 '7일 뒤'로 복사해버리는 기존 시계열 모델의 한계를 극복했습니다. 생물학적 과거 힌트(세포수)를 투입할 때 Log1p 스케일로 압축하여 페널티를 부여함으로써, 모델이 수온, 체류시간, N/P 비율 등 본질적인 '물리·화학적 인과관계'에 집중하여 폭발적인 대발생 임계점(Turning Point)을 선제 포착하도록 설계했습니다.

### 3. 수역 특성을 반영한 듀얼(Dual) AI 아키텍처
대청호 3개 수역의 영양염류 측정 주기 불일치 문제를 해결하기 위해 데이터를 억지로 묶지 않았습니다.
- **문의 수역:** 화학적 영양염류(TN, TP)를 포함한 19개 Feature 학습 
- **추동/회남 수역:** 영양염류를 배제하고 물리·수리적 인자에 집중한 16개 Feature 학습
독립된 병렬 AI 모델(K-Means + MLPRegressor)을 구축하여 특정 지점의 결측치가 전체 예측 성능을 훼손하지 않도록 방어했습니다.

### 4. 도메인 기반 핵심 파생 변수(Feature Engineering)
단순한 센서 데이터 나열을 넘어 조류 발생 메커니즘을 설명하는 파생 변수를 구축했습니다.
- **N/P Ratio (질소/인 비율):** TN / TP
- **Retention Index (체류시간 지표):** 저수량 / 총방류량 (댐 수리학적 정체 수준 반영)

<br>

## 기술 스택 (Tech Stack)
- **Language:** Python 3.13
- **Data Engineering:** Pandas, NumPy
- **Machine Learning:** Scikit-learn (MLPRegressor, KMeans)
- **Visualization:** Matplotlib, Seaborn
